# MOS, ZimaOS, CasaOS and umbrelOS

CannonCommander is in the app stores of these systems too. Each install takes a few clicks and shows the system's own storage folder.

=== "MOS"

    1. Open the [MOS Hub](https://mos-official.net/apps.html?search=CannonCommander) on your server.
    2. Search for **CannonCommander** and install it.
    3. Open it from the app list. It shows `/mnt/cache`.

=== "ZimaOS and CasaOS"

    1. Add the [community store](https://github.com/junkerderprovinz/zimaos-apps#install) to the App Store. The link shows how.
    2. Search for **CannonCommander** and install it.
    3. Open it from the dashboard. It shows `/DATA`.

=== "umbrelOS"

    1. Add the [community app store](https://github.com/junkerderprovinz/umbrel-apps#install) in the umbrelOS App Store.
    2. Install **CannonCommander** from it.
    3. Open it from the home screen. It shows umbrelOS's storage folder.

After the first click you see the two panels:

![The two panels after the install.](../assets/screenshots/panels-dark.png#only-dark)
![The two panels after the install.](../assets/screenshots/panels-light.png#only-light)

To show other folders, add them under **Settings > Sources**. See [Folders](../configuration/folders.md).

Then set a password: [First start](first-start.md).
