# Getting started

CannonCommander comes in two shapes. Pick the one that fits.

| You want | Take | Guide |
|---|---|---|
| Your server's files in the browser, from any device | The container | [Unraid](unraid.md), [MOS, ZimaOS, CasaOS and umbrelOS](app-stores.md), [other Docker hosts](docker.md) |
| The files on the computer in front of you | The desktop app | [Desktop app](../desktop-app.md) |

Both show the same interface. The container adds what only a server can do: several users, share links, WebDAV, remote storage and the MCP server for other machines.

![The two panels right after the first start.](../assets/screenshots/panels-dark.png#only-dark)
![The two panels right after the first start.](../assets/screenshots/panels-light.png#only-light)

Once it runs, read [First start](first-start.md). It opens without a sign-in until you set a password.
